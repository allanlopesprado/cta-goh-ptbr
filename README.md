# Tradução PT-BR — Call to Arms - Gates of Hell: Ostfront

Tradução da interface e dos textos do jogo para português brasileiro.

## Download

[**Baixar a tradução — default.pak**](https://github.com/allanlopesprado/cta-goh-ptbr/releases/latest/download/default.pak)

Baixe o arquivo pelo link acima. Não é necessário baixar o repositório pelo botão **Code > Download ZIP**.

## Como instalar

1. **Feche o jogo.**
2. Na biblioteca da Steam, clique com o botão direito no jogo e abra **Propriedades > Arquivos instalados > Explorar**.
3. Na pasta do jogo, abra **`localizations`** e localize o arquivo **`default.pak`**.
4. Antes da primeira instalação, **guarde uma cópia do arquivo original em outra pasta, fora da instalação do jogo**. Se já usa a tradução, mantenha o backup original que você já possui.
5. Copie o arquivo baixado para `localizations`, com o nome **`default.pak`**, substituindo o arquivo existente.

Pronto: abra o jogo. **Não descompacte o arquivo `.pak`** — copie-o inteiro.

## Atualizar ou remover

- **Atualizar a tradução:** baixe o arquivo mais recente e repita a instalação, mantendo seu backup original.
- **Voltar ao inglês:** com o jogo fechado, na Steam use **Propriedades > Arquivos instalados > Verificar integridade dos arquivos**. Isso restaura os arquivos originais e também pode desfazer outras modificações na instalação.

Atualizações do jogo podem substituir a tradução pelo inglês. Confira se há uma tradução atualizada antes de reinstalar.
